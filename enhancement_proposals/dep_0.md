# DEP 0 - Index of Deadcode Enhancement Proposals (DEPs)

A Deadcode Enhancement Proposal (DEP) is a design document that proposes a change to Deadcode and records the problem, the considered alternatives,
and the chosen solution with its motivation. The published process and template page is
<https://deadcode.readthedocs.io/en/stable/dep.html>.

| DEP | Title | Status | Type | Created |
|---|---|---|---|---|
| [DEP 1](dep_1.md) | More accurate usage detection | Proposed | Feature | 2024-01-14 |
| [DEP 2](dep_2.md) | Fixing code after removal of unused code fragments | Proposed | Feature | 2024-04-16 |
| [DEP 3](dep_3.md) | Removal of unused code might create new unused code | Proposed | Feature | 2024-04-16 |

New DEPs are added by following the published process page. A merged DEP is not edited except to update its status or to add the required sections
on its next substantive change.
